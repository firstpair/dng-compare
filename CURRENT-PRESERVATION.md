# Archive status belongs to the archive

This public repository does not contain photo inventories, live job state,
reports or preservation receipts. A historical deployment used this filename
as a pointer to a private archive; that pointer is intentionally omitted.

For your own archive, inspect `summary.json`, `metadata/summary.json`,
`verification.json` (year pipeline), `deletion-readiness.json` (single-tree
pipeline), the recorded source/reference paths and actual errors. An attempted
run, preserved source code or old status report is not completion proof.
No command in this repository deletes the input trees. Retain an independent
copy before deciding whether an old tree may be removed.
